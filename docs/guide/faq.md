# 常见问题

## 消息中心有记录，为什么手机没收到通知？

1. 打开手机的系统设置，确认 Echo酱有通知权限。
2. 在[网页工作台](/guide/web-console)的「设备管理」查看设备状态，确认设备可接收且没有暂停。
3. 在「频道管理」确认目标频道已对这台设备开启推送。
4. 检查账号的最低通知级别、免打扰时段和频道静音设置。

还收不到时，打开网页上的消息详情查看投递记录。

## 为什么同主题消息没有折叠到一起？

发送时给多条消息填写相同的 `topic`，并确认这些消息都在当前筛选结果里。网页按当前页折叠，App 按已经加载的消息折叠。只有一条同主题消息时会照常显示。参数写法见[消息主题与隐私推送](/guide/api#topic-and-privacy)。

## 为什么通知栏和消息详情显示的内容不同？

发送方启用隐私推送后，系统通知显示指定的替代标题和正文。打开 Echo酱查看消息详情，仍然可以看到原文和主题。

## Webhook 返回 401、404 或 429 怎么办？

| 返回码 | 处理方式 |
|---|---|
| `401` | 如果频道开启了签名校验，请检查签名密钥和时间戳，并用实际发送的原始请求体计算签名。 |
| `404` | 确认请求地址正确，从频道详情重新复制 `push_id`。 |
| `429` | 等待限流结束后再发送，避免连续重试。 |

签名头和计算示例参见 [API 文档](/guide/api#签名计算规则)。

## 还有问题怎么办？

可以到 [GitHub Issues](https://github.com/dorimui/push-docs/issues) 反馈，附上设备型号、App 版本、发生时间及相关的 `message_id`。请先移除截图或命令里的访问令牌、签名密钥和完整 Webhook 地址。
