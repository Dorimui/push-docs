# App 功能说明

Echo酱 App 用于接收和处理推送消息、管理频道、完成决策任务，以及与 Robot 进行对话。登录后，底部导航包含“消息”“聊天”“频道”“我的”四个页面。

## 登录与账号

- 使用邮箱注册账号，按页面提示完成邮箱验证码验证。
- 已有账号可以使用邮箱和密码登录，也可以通过“忘记密码”重设密码。
- HarmonyOS 设备支持“华为账号一键登录”；首次使用时，App 可能要求绑定并验证邮箱。
- 登录状态会保存在当前设备上。登出后，该设备将不再接收当前账号的消息通知。

## 首次使用引导

首次登录后，App 会检查系统通知权限和当前设备的推送状态。如果账号还没有频道，首页会自动显示使用引导：

1. 创建第一个频道。
2. 确认系统通知权限和设备推送状态正常。
3. 通过网页控制台发送第一条通知，并回到“消息”页面查看。

关闭引导后，当前设备会记住该选择，不再自动弹出。需要重新查看时，前往“我的” → “设置” → “使用引导”。

::: tip 收不到通知时
先检查系统是否允许 Echo酱发送通知，再确认目标频道已经启用“推送到此设备”。消息是否成功进入账号，可以在“消息”页面中确认。
:::

## 消息

“消息”页面包含“消息”和“决策”两个页签。

### 查看和筛选消息

- 按关键词搜索消息。
- 按频道筛选消息来源。
- 按通知、聊天、系统告警和决策等消息类型筛选。
- 快速查看未读、待处理、置顶和稍后处理的消息。
- 点击系统通知后，App 会打开并定位对应消息或决策任务。

### 展开或收起同主题消息

同一个主题有多条消息时，列表会把它们折叠成一张堆叠卡片，展示主题、条数和最新消息预览。点击卡片展开，再点「收起」回到折叠状态。没有主题或只有一条消息时，照常显示为单条卡片。

App 加载旧消息时，同主题的消息会并入已有分组。[网页版消息中心](https://echo.dorimu.cn/dashboard/user/messages)也支持折叠，条数按当前页计算。

### 处理消息

- 点击单条消息卡片查看完整内容、主题和来源。列表卡片省略来源。
- 将消息标记为已读或直接删除。
- 左滑折叠卡片可删除组内当前已加载的消息。右滑可将组内未读消息一起标为已读。
- 置顶重要消息，稍后可以取消置顶。
- 设置“稍后处理”时间；App 会尝试打开系统日历，供你确认保存提醒。
- 取消已经设置的稍后处理。
- 长按消息进入多选状态，批量标记已读或批量删除。

删除消息后无法在 App 中恢复，请确认不再需要后再删除。

如果发送方启用了[隐私推送](/guide/api#topic-and-privacy)，设备通知会显示发送方设置的替代标题和正文。打开消息详情可以查看原文。

### 处理决策任务

决策任务会显示标题、可选操作、截止时间和当前状态。任务仍处于待决策状态时，可以直接选择操作；任务结束后会显示最终结果和决策时间。

已结束的决策任务可以删除。删除后，它会同时从决策列表和消息中心移除。

## 频道

频道用于区分消息来源、推送级别和接收设备。每个频道创建后都会生成唯一的 `push_id`，网页控制台和 Webhook API 都可以使用它发送消息。

### 创建频道

1. 打开“频道”页面。
2. 点击右下角的添加按钮。
3. 填写频道名称和说明，并选择消息推送级别。
4. 根据需要开启“推送到此设备”。
5. 创建成功后复制 `push_id`，用于网页控制台或 API 接入。

### 管理频道

点击频道列表项可以查看频道详情，并执行以下操作：

- 查看和复制 `push_id`。
- 修改消息推送级别。
- 开启或关闭当前设备接收该频道推送。
- 删除频道。

删除频道会停止通过该频道继续推送消息，操作前请确认相关服务不再使用对应的 `push_id`。

## 聊天与 Robot

“聊天”页面用于创建 Robot 会话、查看聊天记录和管理 Robot。

### 管理 Robot

点击聊天页面右上角的 Robot 图标进入“机器人管理”：

- 新增 Robot，填写名称和说明。
- 编辑 Robot 的名称、说明和启用状态。
- 删除不再使用的 Robot。

创建成功后会显示 `robot_id` 和一次性的 `endpoint_secret`。`endpoint_secret` 只在创建完成时展示一次，请立即保存；Robot 服务端的连接、签名和消息格式参见 [API 文档](/guide/api#robot-接入)。

### 创建和使用会话

创建会话时需要选择一个可用的 Robot，也可以选择关联频道。进入会话后可以：

- 发送普通文本或 Markdown 消息。
- 查看 Robot 返回的文本、Markdown 和卡片消息。
- 点击卡片中的操作按钮。
- 双击消息复制内容，或长按打开复制菜单。
- 在允许的时间窗口内撤回自己发送的消息。
- 查看会话详情及关联频道。

会话刚打开且详情仍在加载时，输入区域会暂时不可发送；加载完成后会自动恢复。

### 归档、恢复和删除会话

聊天页面可以在“活跃”和“已归档”之间切换。长按会话会打开底部操作菜单：

- 活跃会话：`归档`、`删除`。
- 已归档会话：`恢复`、`删除`。

归档后的会话仍可查看历史消息，但处于只读状态，不能继续发送。恢复时，App 会检查关联 Robot 是否仍然存在且可用；Robot 不可用时会提示无法恢复。

删除会话后不可恢复。

## 我的与通知设置

“我的”页面提供以下功能：

- 修改昵称等个人资料。
- 选择 App 主题色。
- 打开网页控制台。
- 进入反馈、关于和设置页面。
- 登出当前账号。

在“我的” → “设置” → “通知设置”中，可以配置：

- 最低通知级别。
- 一个或多个免打扰时间窗口及其时区。
- 按频道静音。

设置页面还可以重新打开“使用引导”，或发起账号注销。账号注销后有 72 小时恢复期，在恢复期内重新登录可以取消注销。
