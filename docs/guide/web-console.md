# 网页工作台

登录 [管理后台](https://echo.dorimu.cn/dashboard/user/) 后，可以在浏览器里查看消息、管理频道和设备，也可以创建 API 使用的访问令牌。

## 首次推送

1. 在手机上安装 Echo酱，登录同一个账号并允许系统通知。
2. 在网页右上角打开账号菜单，选择「首次推送向导」。
3. 检查可接收推送的设备，选择已有频道或新建频道，再选择要接收通知的设备。
4. 填写测试通知的标题和正文，发送后到手机通知栏和消息中心查看。

如果没有可用设备，先打开手机上的 Echo酱，再回到向导点击「重新检查」。开启签名校验的频道可以复制命令到终端，按[签名计算规则](/guide/api#签名计算规则)发送，然后把返回的 `message_id` 填回向导验证。

## 消息中心

- 在「消息」和「决策」页签之间切换。
- 按关键词查找消息，或按类型和状态筛选未读、待处理、置顶及稍后处理的消息。
- 同一页有多条同主题消息时，点击折叠卡片可以展开。点击其中一条消息可以查看主题、正文和投递详情。
- 勾选消息后可批量标记已读或删除。需要晚点处理的消息可以设置稍后提醒。

## 频道和设备

「频道管理」可以创建频道、复制 Webhook 地址、修改通知级别，以及选择哪些设备接收该频道的推送。

「设备管理」可以查看已登录的设备和推送状态。看到「已暂停」或推送状态不可用时，请按页面提示恢复接收，或在对应设备上打开 App 重新登录。

在右上角账号菜单进入「设置」，可以调整最低通知级别、免打扰时段和频道静音。需要排查某条通知时，请参阅[常见问题](/guide/faq)。

## 访问令牌

在右上角账号菜单选择「访问令牌」，点击「创建令牌」，按用途选择权限并设置有效期。令牌只在创建成功时显示一次，请及时保存。

- 使用 HTTP 接口查询消息，请参阅[消息中心 API](/guide/message-api)。
- 从 Codex、Claude Code 等客户端发送通知，请参阅 [MCP 接入](/guide/mcp)。
